# Shopee

Nesta atividade, desenvolveremos um Readme, sobre um site já criado.

# Descrição

A Shopee é a principal plataforma de e-commerce do Sudeste Asiático e Taiwan, oferecendo aos usuários uma experiência de compra online fácil, segura e rápida, apoiada por forte suporte de pagamentos e logística. A empresa pertence ao grupo Sea Limited, sediado em Singapura, e opera em múltiplos países, incluindo Indonésia, Malásia, Tailândia, Vietnã, Filipinas, Taiwan e Brasil.
  A plataforma reúne, em um único aplicativo/site, funcionalidades de catálogo de produtos, pagamentos, logística, comunicação entre comprador e vendedor e ferramentas de marketing para lojistas, sustentadas por uma infraestrutura de backend capaz de processar centenas de bilhões de requisições por dia, segundo relato oficial da própria equipe de engenharia da Shopee.

# Publico alvo

- Consumidores finais (compradores);
- Vendedores e lojistas;
- Criadores de conteúdo/afiliados;
- Desenvolvedores e parceiros técnicos, que integram sistemas externos por meio das APIs abertas da Shopee.

# Funcionalidades

- Compras;
- Ofertas de promoções (descontos, desafios);
- Sistema de pedidos, com acompanhamento e rastreamento de entregas;
- Avalição de produtos;
- Programa de afiliados e conteúdo social (Shopee Live, Shopee Feed);
- Marketing.

# Tecnologias utilizadas

- Go (Golang) — linguagem principal do time de Backend Engineering;
- JavaScript - como linguagem principal do frontend;
- React Native - Utilizado em partes do desenvolvimento mobile
- Apache Spark — processamento distribuído de dados;
- Apache Hive — data warehouse para grandes volumes de dados.

# Requisitos tecnicos

- Aplicativo mobile: smartphone com Android ou iOS;
- Acesso via navegador: qualquer navegador atualizado (Chrome, Safari, Edge, Firefox) em desktop ou mobile;
- Conexão com a internet estável (Wi-Fi ou dados móveis);
- Conta de e-mail ou número de celular para cadastro e login.
